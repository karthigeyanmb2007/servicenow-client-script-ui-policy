# Project Summary

## Project Title
Implement Client Script & UI Policy (Incident)

## Objective
To improve the ServiceNow Incident form by using Client Script and UI Policy.

## Client Script
The Client Script displays an information message when the Incident form loads.

## UI Policy
When the Incident State is changed to Resolved:

- Close Code becomes mandatory.
- Close Notes becomes mandatory.
